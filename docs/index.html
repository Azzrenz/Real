你能让它干什么

不是问它「怎么写」，而是直接说「去做」。

整理一堆乱文件

「把 D:\素材 里的照片按拍摄日期分到年-月文件夹」——它自己建目录、移动、重名去重。

批量改名与归档

「这个文件夹里的录音，按项目和日期重命名」——改完给你一份对照表。

跑一条视频流水线

抓素材 → 去字幕 → 换文案 → 配音 → 合成 → 终审，一条命令跑到底。

给项目加功能

「加一个深色主题」——它读代码、改多处、跑测试，改坏了自己回滚重来。

读一堆文档给你结论

「把这 30 份合同里的付款条款挑出来，列成表」——它逐份读，不靠猜。

重复劳动全交出去

定时跑、异常重试、跑完给你结果；出错了会停下来问，不会闷头乱改。

三分钟跑起来

不需要装 Node、Rust 或任何运行环境。

  1. 解压到 D:\Real（路径别带中文），双击 real-client.exe
  2. 申请 API Key（DeepSeek 或智谱 GLM，二选一，约 5 分钟，几块钱起用）
  3. Settings → Model & credentials 填入 Key → Test connection → Save，然后 New task 选个文件夹开工
首次启动窗口可能要等几秒：后端要建库、起服务。数据全部落在本机 %APPDATA%\real-agent，只有对话内容会发给模型接口。

适合谁，不适合谁

适合

有明确想做的事、但不会写代码的人。
愿意把需求说清楚，能判断结果对不对的人。
手上有一堆重复活、又不想学编程的人。

不适合

想要「打开就有一排现成按钮」的人。
不愿意花五分钟申请 API Key 的人。
把电脑当黑盒、不接受它读写文件的人。

边界说清楚：它能在你指定的文件夹里读写和执行命令，权限等于你本人。第一次用请先在空文件夹里试， 重要文件先备份；危险操作会弹确认，但那是防手滑，不是安全边界。
