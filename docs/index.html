本地 Agent 工作台

给一个文件夹和一句话。它自己读文件、改文件、跑命令、看报错，一轮一轮改到真正交付——不是聊天，是收敛。

下载 Windows 便携版 · 12MB 在 GitHub 上看源码
主界面：左侧会话列表，中间对话与工具卡片，底部是派活的输入框

它和聊天窗的区别

四件事决定了它能不能真的把活干完。

收敛循环，不是一次问答

每轮要么真的改了文件，要么记为「无改动」。只说「改好了」却没动文件的那一轮，不算数。

改了没有，不靠模型自己申报

工具回执进流，下一轮由系统核验，而不是相信模型的自述。

危险操作有确认门

删除文件、执行 shell 命令前会先问你。确认门不是安全边界，是防手滑。

全程可审计

工具调用、文件写入、命令输出都留成卡片，随时点开回看。

三分钟跑起来

不需要装 Node、Rust 或任何运行环境。

  1. 解压到 D:\Real（路径别带中文），双击 real-client.exe
  2. 申请 API Key（DeepSeek 或智谱 GLM，二选一，约 5 分钟，几块钱起用）
  3. Settings → Model & credentials 填入 Key → Test connection → Save，然后 New task 选个文件夹开工
首次启动窗口可能要等几秒：后端要建库、起服务。数据全部落在本机 %APPDATA%\real-agent，只有对话内容会发给模型接口。

界面

Settings → Model & credentials：DeepSeek 与智谱 GLM 可同时配置，换模型不用重启
