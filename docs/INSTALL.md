# Real 使用说明

**适用版本**：v0.1.0 · Windows x64
**项目地址**：https://github.com/Azzrenz/Real

Real 是一个**本地 AI Agent 工作台** —— 给它一个项目目录和一句话需求，它在那个目录里干活：
读代码、改代码、跑命令、留日志，每一轮都留证据。

---

## 一、两种装法，选一个就行

### 方式一：安装包（推荐给普通用户）

**文件**：`Real_0.1.0_x64_en-US.msi`（约 217 MB）

1. 双击这个 `.msi` 文件
2. 一路点「下一步」→「安装」（中途会请求管理员权限，正常）
3. 装完桌面会出现 **Real** 图标，双击打开

**不需要**装 Node.js、Rust 或任何运行环境 —— 后端程序和 WebView2 运行时都已经包在里面了。

- 安装位置：`C:\Program Files\Real`
- 适合：就想双击装完用的人

### 方式二：便携版（U 盘、换电脑、不想安装）

**文件**：`Real-0.1.0-win-x64.zip`（约 12 MB）

1. 把 zip 解压到**任意目录**（U 盘也可以）
2. 双击解压出来的 **`real-client.exe`**

卸载就是删掉这个文件夹。注意**数据不在文件夹里**（默认在 `D:\RealData`，见第四节），换电脑时要单独搬。

- 前提：系统要**已有 WebView2 运行时**。
  Windows 11 和较新的 Windows 10 都自带；老系统建议改用方式一。
- 适合：带着走、不想往系统里装东西

---

## 二、第一次打开

- **首次启动窗口要等几秒** —— 后端要先建数据库、起本地服务，之后每次打开都快
- 如果双击后窗口没立刻出现，**先等 10 秒**，不要连续双击

## 三、填 API Key（第一次必须做）

Real 自己不思考，需要接一个模型作为大脑。没填 Key 时程序退回内置的**模拟模型** ——
界面流程能走通，但回复内容不是真的；要真正干活，先填 Key。

1. 打开 Real → 左下角「**设置**」
2. 填入 **DeepSeek** 的 API Key（在 https://platform.deepseek.com 申请）
3. 保存

## 四、数据存在哪

默认在 **D 盘**：

```
D:\RealData
```

里面有：`db/`（聊天记录）、`logs/`、`spill/`、`tmp/`、`skills/`、`providers/`。

机器上没有 D 盘时，自动回落到 `%APPDATA%\real-agent`。

**想换位置**：打开「设置 → 数据目录」，直接点盘符（选 `E:` 就落 `E:\RealData`），或手填任意绝对路径；重启后生效，启动时会把旧目录的数据自动迁到新位置（源目录保留，可回滚）。也支持环境变量 `REAL_DATA_DIR`。

> 便携版提示：程序文件夹可以随意搬，但数据在 `D:\RealData`，换电脑时要单独把它一起带走。

## 五、怎么卸载

| | 怎么卸 |
|---|---|
| 方式一（安装包）| 系统「设置 → 应用」里找到 Real 卸载；数据目录 `D:\RealData`（无 D 盘时为 `%APPDATA%\real-agent`）想删再手动删 |
| 方式二（便携版）| 直接删掉那个文件夹，就这样 |

## 六、注意事项

- 程序**只监听本机回环地址（`127.0.0.1`）**，**没有登录认证** —— 设计前提是单人本地使用
- **请不要把它暴露到公网**（详见 [SECURITY.md](https://github.com/Azzrenz/Real/blob/main/docs/SECURITY.md)）
- 它会在你指定的项目目录里**读写文件、执行命令** —— 这是它的功能，不是缺陷。
  请只把它指向**你信任的目录**
- 危险操作会走「确认门」弹窗，但请把它当作**降低误操作概率的机制，而不是安全边界**
