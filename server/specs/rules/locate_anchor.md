**锚点选择**：错误码 > 符号 > 字面量 > 文件名——**越独特越准**。

**降级路径**（前一档不中才往下走）：子串 → 大小写放开 → 拆词去前缀 → **换证据源**（配置 / 日志 / 测试名 / git 历史）。**全库枚举是最后手段。**

**一锚多查**：一次查多个变体（`grep -rn -E 'a|b' <目录>`——Git Bash 原生，`-n` / `-A/-B/-C` / `\|` 都可用）。

**命中后**：用 `read` 拿准行号 ± 上下文再改；真无锚点，才退回列目录。

**改多文件前先盘点**：一条 `run` 列出各文件现状与差异，**禁止拿 A 文件的锚点去套 B 文件**。
