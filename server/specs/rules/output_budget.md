`run` 输出默认控量——头 / 尾部够了立即停。

| 场景 | 做法 |
|---|---|
| `grep` 有命中 | 只打命中段（`-C 2` 上下文，勿 `-A 999`） |
| 看前几行 | `head -n 20` 够判断即可 |
| 全文输出 | 重定向到**本任务 `cache/` 下**再过滤（不灌对话） |
| python 临时脚本 | 只打结论行，不 `print(len(...))` 爆炸 |
| 目录树大 | `dir /b` 只列名 |
| 进程 / 端口 | `netstat -ano \| findstr :端口` 只看目标 |
| 网页抓取 | `curl -s URL` 接管道过滤，不整页灌入 |

**收敛信号**：输出匹配目标即停，不跑完整个文件。

**超线落盘（spill）是信号，不是失败**——它在说「这条命令问得太宽」：

| 症状 | 做法 |
|---|---|
| 输出被 spill | 改写命令**只打要点**，**不去读快照** |
| 真要全文 | 读快照**一次读足**；别重跑原命令——重跑 = 再落一次盘 |
| `read` 大文件被降档 | 直接 `mode=lines` 带 `start_line`/`end_line`；先小后大试探 = 多烧一轮 |
| 想换个统计口径再算一遍 | 禁止；证不出就换证据源或问一句 |
