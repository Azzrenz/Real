`run` 输出默认控量——头/尾部够了立即停，全文跑完才叫负担。

| 场景 | 做法 |
|---|---|
| `grep` 有命中 | 只打命中段（`-C 2` 上下文，勿 `-A 999`） |
| 看前几行 | `head -n 20` 够判断即可 |
| 全文输出 | 重定向到**本任务 `缓存/` 下**的文件再过滤（不灌对话） |
| python 临时脚本 | 只打结论行（`print(f"{k}: {v}")`），不 `print(len(...))` 爆炸 |
| 目录树大 | `tree /F \| more` 或 `dir /b` 只列名 |
| 进程 / 端口 | `netstat -ano \| findstr :端口` 只看目标 |
| 网页抓取 | `curl -s URL` 接管道过滤，不整页灌入 |

**收敛信号**：输出匹配目标即停（如找到目标文件的路径/行号就停止命令），不跑完整个文件。
