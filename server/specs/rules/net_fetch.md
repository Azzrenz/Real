| 场景 | 入口 |
|---|---|
| 定向结构化 API（GitHub / PyPI / npm 等有官方 search endpoint） | `run` + `curl`——要星数/版本号等结构化字段时是唯一正解 |
| 抓指定网页 | `run` + `curl -s URL` 接管道过滤 |
| 通用关键词搜索 | 工具面**没有**搜索工具（2026-09-16 收四件套）——`run` + `curl` 打**已知站点**的 search endpoint，**不要臆造搜索 URL** |

**解析纪律**：多份数据**写一个 python 脚本一次解析落盘**，勿一件一件分段处理。
URL 带中文 / 空格 / `&` 必须加引号（**curl 退出码 3 = URL 引号问题**）。
