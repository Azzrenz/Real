**改前留底**：动源文件前先复制一份到工作区**外**的目录（可整目录回退）。用 `shutil.copy2` 保留时间戳。

**备份放哪**：不要放在被改目录内部（会被下一轮当成残留清掉，也污染别人的工作区）；放在项目树之外、带日期的目录里。

**"哪份是基线"看权威源**：版本库标签 / 发行包 / 题目原始目录 —— **不是**看哪份文件更旧、也不是看备份。备份常常是"已经改过的状态"。凭直觉从上游拉一份覆盖，可能把题目/项目**提前改好**了。

**恢复判据是逐字节**：恢复后逐文件核哈希（不是只看大小或 mtime），并清掉编译产物（`__pycache__`、`.pytest_cache`、生成物）。

**恢复后统一时间戳**：若原目录有一套规范化的 mtime，覆盖后要跟着设回同一基准 —— 否则下一轮按 mtime 排查"哪些被改过"会误判。
