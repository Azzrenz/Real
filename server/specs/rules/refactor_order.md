**大批量改动（拆分 / 搬移 / 批量替换 / 改名）的固定次序**：

① **先扫引用面** —— 这个规则/符号被谁引用（一条命令扫全仓）；拆完能做到「**外部零改动**」全靠它；
② **用脚本机械切** —— 不要逐段手改（人工漏一处看不出来）；
③ **改完必须对账** —— 新旧**逐行**比对（只比非空、非注释行），「只在旧有」必须为 0 或逐条可解释。**编译通过 ≠ 内容没丢**；
④ **动刀前留底** —— `write` / `modify` 自带改前副本；用 `run` 脚本改源码时先把原件复制到**本任务 `缓存/`**（**不要往项目里新建目录存临时件**）。
