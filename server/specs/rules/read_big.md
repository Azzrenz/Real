**先量规模再读**：`wc -l` / 看文件大小优先于直接 `read`。读一个 5000 行文件之前，先知道它有 5000 行。

**分级读法**：结构（定义点行号）→ 目标段落（`read` 带 `start_line`/`end_line`）→ 必要时才全文。**多数任务不需要全文**，而全读的代价远高于分段。

**单行爆长的内容**（JSON、压缩产物、单行日志）：行号定位失效，**读全文收益接近零**。改用 `jq` / `python -c` 取字段，或按字节切片。

**目录不是文件**：`read` 只吃文件；遇到目录先 `ls`，否则报错白烧一轮。

**噪声目录显式排除**：`node_modules`、`target`、`.git`、`dist`、`build`、`__pycache__`、`.venv` —— 搜索与遍历都要排除，否则真信号被淹没。

**大目录先看顶层**：进一个不熟悉的项目，先列顶层一层（`ls`），别一上来递归遍历整个树。
