**要给人「看」的东西，落成单文件 HTML，不是一堆 markdown 表格。**

判据一句话：**这张内容，眼睛扫一遍会比逐行读更快吗？** 是 → HTML；不是（纯结论、纯清单）→ 写进回复就够了，别为了 HTML 而 HTML。

## 硬约束：单文件自包含

右侧栏是用 `iframe sandbox` 预览的，**拿不到任何外部资源**：

| 项 | 做法 | 违反的后果 |
|---|---|---|
| 样式 | `<style>` 内联 | 外部 `.css` 不加载，页面裸奔 |
| 脚本 | `<script>` 内联 | 同左 |
| 图表 | **内联 SVG** 或纯 CSS 画 | 引 CDN 的 ECharts / Chart.js 在沙箱里不保证能加载 |
| 图片 | `data:` URI 或绝对路径 | 相对路径在沙箱里解析不到 |
| 字体 | 系统字体栈 | 外部字体不加载，静默回退 |
| 链接 | 绝对 URL | 相对链接点了没反应 |

**验收标准只有一条：这个 `.html` 单独拖进浏览器也能看。** 达不到就是没写完。

## 真要引外部依赖时（两种交付形态别混）

| 交付给谁 | 依赖怎么放 | 判据 |
|---|---|---|
| **右侧栏预览**（默认） | 全内联：`<style>` / `<script>` 内联，图走 `data:` URI 或内联 SVG | 沙箱 `iframe` 拿不到任何外部资源 |
| **给人双击打开的网页** | 外部 JS/CSS **本地化到同目录**（如 `three.min.js`），页面用**相对引用**（`src="three.min.js"`） | 双击 `file://` 无联网依赖 |

大库（three.js / 图表库）没法内联时才走第二行 —— 此时右侧栏预览会失效，要在回复里说明用哪种方式打开。

## 落到哪、怎么说

- 写进**工作区**（当前任务目录），路径用**绝对路径**；
- 路径放**正文或行内代码**里让人点得开——**代码块里点不开**；
- 回复里补一句**这个文件能看什么**，不要把交付推给「详见文件」。

## 报告体：同类记录多到一张表读不动时

判据是**条目数**：几十条以上、或者本身有分组维度，平铺的列表就变成"翻不动"的东西。

- **顶部 KPI 卡**：3~6 个数字，先给总量与分布；
- **每个分组建一个折叠块**，标题旁标条目数 —— 别一屏全铺开；
- **一个搜索框全局过滤**：命中的组自动展开、一条不中的组整块隐藏；
- **表头 sticky**，语义标签（ok / warn / bad / new）用色分级；
- **每一条都要带一句人话说明** —— 只列裸数据，看的人还得回去翻原始文件，等于没交付。

**别手搓这份形态**：`python <脚本库>/report.py --help`。数据本来就在文件里时让它直接读那张表
（`--data` / `--group` / `--note` / `--tag`），**不要把上千行重新誊进你的输出** ——
那既慢，又随时可能被 max_tokens 截断。

## 常见形态对照

| 要做的事 | 产物 |
|---|---|
| 一批数据要对比 | 表格 + 关键差异着色 |
| 趋势 / 分布 | 内联 SVG 折线、柱状、堆叠条 |
| 多方案取舍 | 对照表 + 推荐项高亮 |
| 排查 / 溯源结论 | 时间线 + 证据链 |
| 汇报 / 概览 | 单页 dashboard（卡片网格） |

**配色走变量**（`:root { --fg: …; --bg: … }`），深浅色两套不必都做，但**别写死黑字白底**——用户可能是深色主题。
