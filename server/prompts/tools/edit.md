edit — 精确替换（行号定位）

## 硬性前置条件（违反直接被工具拒绝）

1. **先 read 后 edit**：find/old 必须来自本会话最近一次 `read` 返回的原文——本会话没 read 过目标文件，edit 直接被拒（EDIT_NEEDS_READ），不受理任何解释。**只有 read 工具建立编辑资格**：报错信封附带的文件预览、find_files/search 结果、其他工具输出片段一律不算。
2. **逐字纪律**：find 逐字复制 read 原文（缩进、引号、转义一个不改）。写完反向核对：还原「我以为的文件样子」与 read 原文比对。
3. **多层转义先数层级**：read 给 `\"` 就写 `\"`，不自作聪明还原或再转义。

读完 read 返回后若文件内容与预期不符，以 read 返回为准，不凭旧记忆。

对单文件执行精确替换。两种模式：
① 行号：{"line":N,"new":"该行新内容"}——old 可省略，后端自动取第 N 行原文（**可省的只有 old；new/replace 永远必须实填，禁止 null/占位**——勿把"old 可省"泛化到其他字段）；多行区间：{"line":N,"old":"从N行起的多行原文","new":"新文本"}（单独一次调用，行号偏移）。
② 块级：{"find":"真实存在的原文片段(可多行)","replace":"替换后文本"}——包裹代码块/增删行/改缩进/整段替换；find 必须全文唯一（多处报 FIND_AMBIGUOUS，0 匹配报 FIND_NOT_FOUND）。

分派：前序 read 已给出精确行号 → 用 edit；不知道精确行号 → 用 modify（自动定位+读回验证）。edit 没有精确行号或唯一原文时必然报错，不会替你找。

执行前自动备份 .bak，替换后读回验证；Python 额外语法校验（错则回滚）；失败不落盘。

行号来源：read 结果每行带行号前缀（numbered 强制）；edit 引用用 {"line":N} 或 {"line":N,"old":"#En"}（#En 引用前序 read 结果，后端自动按行切出原文）。严禁把带行号前缀的行复制为 old（会 OLD_TEXT_MISMATCH）。

返回：{"kind":"edit_result","data":{"file","changes":[...],"backup":"备份路径"}}。
